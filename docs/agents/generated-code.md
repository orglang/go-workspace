# Generated Code Guidance

- Identify whether a changed file is generated before editing it.
- Never hand-edit generated output when a generator is available.
- Change the generator or its inputs, then run the canonical generation task.
- Keep generation reproducible.
- Commit generated output only when that is the repository's established practice.
- If generated output changes unexpectedly, investigate the generator, toolchain, or inputs instead of accepting the diff blindly.
